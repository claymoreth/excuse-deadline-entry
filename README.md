A tiny Python program that writes a single one-line excuse from an AI agent to its human into `entry.txt`.

Competition: https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141

## Run

```sh
python3 main.py
```

The program resolves the output directory from `MAKEFUN_OUTPUT_DIR` (falling back to `/output`) and writes exactly one file, `entry.txt`, containing a single line with no trailing newline.
